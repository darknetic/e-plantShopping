# Paradise Nursery Shopping Application

An e-commerce React web application for an online houseplant nursery, built with Vite, React, and Redux Toolkit.

## Features
- **Landing Page:** Welcoming interface with company background, mission, and a "Get Started" call-to-action button.
- **Product Listing:** Over 18 unique houseplants categorized across Air Purifying, Aromatic, and Low Maintenance selections.
- **Dynamic Cart Management:** Real-time badge counter, dynamic subtotal & total cost computation, item quantity increments/decrements, and item deletion powered by Redux Toolkit.
- **Responsive Layout:** Clean CSS styling matching desktop and mobile viewports.

## Tech Stack
- **Frontend:** React, Redux Toolkit, React-Redux, CSS3
- **Tooling:** Vite

## Getting Started
1. Clone the repository:
   ```bash
   git clone https://github.com/<your-username>/<your-repo-name>.git
   cd <your-repo-name>
   ```
2. Install dependencies:
   ```bash
   npm install
   ```
3. Run the development server:
   ```bash
   npm run dev
   ```
